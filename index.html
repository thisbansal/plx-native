PlxNative (Arr Edition)

LG webOS Homebrew Repository

Custom build of PlxNative with built-in Radarr and Sonarr integration.

Add to LG TV Homebrew Channel:

  1. Open Homebrew Channel on your LG TV.
  2. Go to Settings → Repositories → Add Repository.
  3. Enter the following URL:

https://thisbansal.github.io/plx-native/repo.json

Manual Install:

Download the latest .ipk package from GitHub Releases and drag-and-drop into webOS Dev Manager.
